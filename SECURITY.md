## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability or have concerns regarding the potential misuse of this project, please report it responsibly.

### How to Report
Please do **not** open a public issue on GitHub. Instead, report security vulnerabilities through one of the following channels:
- **Email**: `gurvin.singh@example.com` (Replace with actual contact if available, or use GitHub Security Advisories)
- **GitHub Security Advisory**: Use the "Report a vulnerability" tab if enabled on this repository.

### Response Timeline
- We will acknowledge your report within 48 hours.
- We will provide an estimated timeline for a fix or mitigation within 1 week.
- Public disclosure will be coordinated after a fix has been verified.

## ⚠️ Responsible Usage & Disclaimer

This project is designed for **educational and home automation purposes only**. It demonstrates how infrared signals can be captured and replayed to control personal devices.

### Ethical Guidelines
1.  **Authorization**: Only capture and replay signals for devices you own or have explicit permission to control.
2.  **Environment**: Use this software only in controlled environments (e.g., your own home).
3.  **No Malicious Intent**: Do not use this project to disrupt public services, interfere with others' property, or violate any laws.

### Risks
- **Signal Replay**: Replaying signals without authorization can be considered a security violation in some contexts.
- **Interference**: Improper use of high-power IR transmitters can interfere with legitimate device operation.

**The authors are not responsible for any misuse of this software or damage caused by its operation.** By using this code, you agree to adhere to these ethical guidelines.
